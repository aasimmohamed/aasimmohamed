Role-based views, request tracking, task scheduling, real-time notifications, and a German-language UI. Published on the app stores and still actively maintained, on both mobile and web. *(Ionic • PHP • Node.js)*
- 📡 **COMSOL** — Telecom operations platform for a German client with a dynamic provision calculation engine. - ✈️ **Onres 24** — Flight tracker app for Android and iOS, built for aviation clubs and fleet operators handling 20,000+ flights a year.
